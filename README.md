## <img src="https://api.iconify.design/mdi/information-outline.svg?color=%2338BDF8" width="24" style="vertical-align:middle"/> About the Project

**Bewerbungs.online** is a **SaaS platform** built to help students and job seekers — especially those looking for internships (*Praktikum*) and job opportunities in Germany — go through the application process faster and with less friction.

The user brings their own **CV** (uploaded, not generated by the platform) and uses Bewerbungs.online to generate a personalized **cover letter (Lettre de Motivation / Bewerbungsschreiben)**, search opportunities by city and sector, and let the platform handle the repetitive parts of the job search: finding relevant openings, extracting contact emails, and sending applications automatically.

Access to the platform is **pack-based**: a visitor picks the pack that fits their needs, and access is unlocked through an activation code once the purchase is confirmed (see [How It Works](#-how-it-works--pack--activation-model) below).

The platform is designed around one goal: **reduce the time between "I need an internship" and "my application is sent."**

## <img src="https://api.iconify.design/mdi/cash-check.svg?color=%2338BDF8" width="24" style="vertical-align:middle"/> How It Works — Pack & Activation Model

Bewerbungs.online is a **SaaS with manual onboarding**: instead of a fully self-serve checkout, each subscription starts with a lead handled personally by the admin. The flow is:

1. **Pack Selection** — The visitor browses the available packs and chooses the one that fits their needs (features included and access period).
2. **Lead Received** — The admin receives the lead with the client's choice and contact details.
3. **Client Contact** — The admin reaches out to the client to confirm the pack and finalize the details.
4. **Payment** — The client pays for the selected pack.
5. **Activation Code Sent** — Once payment is confirmed, the admin sends the client an activation code.
6. **SaaS Access** — The client enters the code to unlock the platform for the duration of the selected pack's period.

This model gives the admin full control over lead qualification and payment confirmation before granting access, rather than relying on automated self-checkout.

## <img src="https://api.iconify.design/mdi/sitemap.svg?color=%2338BDF8" width="24" style="vertical-align:middle"/> Architecture

Bewerbungs.online follows a decoupled frontend/backend architecture:

1. **Frontend (React + Tailwind CSS)** — Handles the user interface: pack selection, CV upload, cover letter generation, search filters, and the applications dashboard.
2. **Backend (FastAPI / Python)** — Exposes REST APIs for cover letter generation, opportunity search, email scraping, automated application sending, and activation-code verification.
3. **Scraping & Automation Layer** — Collects job listings and contact emails from external platforms and triggers the automated application workflow.
4. **Access & Licensing Layer** — Validates activation codes and enforces the access period tied to the client's selected pack.
5. **Data Layer** — Stores user profiles, uploaded CVs, generated cover letters, search results, and application history.

The frontend communicates with the backend exclusively through REST APIs, keeping the interface fully decoupled from the business logic and automation layer.

## <img src="https://api.iconify.design/mdi/shield-alert-outline.svg?color=%2338BDF8" width="24" style="vertical-align:middle"/> Responsible Use

Automated email scraping and application sending are powerful features and should be used respectfully:

* Only contacts relevant to genuine job or internship applications should be targeted.
* Users are responsible for complying with applicable data protection regulations (e.g. GDPR) and each platform's terms of service.
* The tool is intended to assist genuine candidates, not to enable spam or mass unsolicited outreach.
